Summary

The sinking of the Titanic is a famous shipwreck in history, and predicting the survival probability of passengers has always been a classic problem in the field of machine learning. This project aims to predict the survival probability of Titanic passengers through five different machine learning models (Logistic Regression, Random Forest, XGBoost, LightGBM, TabNet) and compare the performance of each model. We use the Titanic dataset provided by Kaggle to train and optimize each model through data preprocessing, feature engineering and other steps. The interpretability analysis of the model was carried out by using the SHAP (SHAPLEY Additive exPlanations) tool, and the predictive impact of various characteristics (such as gender, ticket rank, etc.) on the survival probability was discussed, and the possible ethical problems of the model were discussed. Experimental results show that LightGBM has outstanding performance and efficiency, and TabNet has certain advantages in interpretability. This study not only provides a new perspective for the survival prediction problem of Titanic, but also provides a useful reference for the interpretability and ethical analysis of machine learning models.

Introduction

The Titanic was a luxury passenger ship built in 1912, but unfortunately sank after hitting an iceberg on its maiden voyage, causing a large number of casualties. This incident has sparked widespread attention and discussion, and has also prompted people to continue to explore various factors that affect the survival of passengers, such as gender, age, cabin class, etc. In the field of machine learning, the Titanic passenger survival prediction problem has become a classic case, attracting many researchers to try different methods to improve the prediction accuracy.

Related Work

Predictive modeling on the Titanic survival dataset has long served as a canonical problem in introductory machine learning (ML) courses and research demonstrations due to its manageable size, binary classification nature, historical context, and structured tabular format. Researchers and practitioners alike have leveraged this dataset to explore classical statistical models, ensemble techniques, and advanced interpretability tools.

Method

3.1 Dataset Description

The dataset used is the Titanic dataset from the Kaggle competition, comprising 891 training samples with 11 key features including passenger demographic, socio-economic, and travel information (e.g., Pclass, Sex, Age, Fare, SibSp, Parch, Embarked). The target variable is Survived, a binary indicator of passenger survival. Data was split into training (80%) and validation (20%) sets using stratified sampling to preserve class distribution.

3.2 Data Cleaning

Missing values in the Age, Embarked, and Fare columns were imputed using domain-informed strategies: median imputation for Age and Fare, and mode imputation for Embarked. Categorical variables (Sex, Embarked) were encoded using label encoding and one-hot encoding as appropriate. Outliers in Fare were capped to reduce skewness.

3.3 Feature Engineering

Feature extraction was performed to enhance model expressiveness. Titles were extracted from the Name field to capture social status, and family size was computed from SibSp and Parch. A new binary feature IsAlone was derived to indicate solo travelers. Continuous features like Fare and Age were discretized into quantile bins to model non-linear effects.

3.4 Normalization

Standardization was applied to continuous features (Age, Fare) to normalize input scales for models sensitive to magnitude differences, such as SVM.

3.5 Model Selection

To ensure both performance diversity and methodological rigor, five supervised classification algorithms were selected: Logistic Regression, Random Forest, XGBoost, LightGBM, and TabNet. These models span a range of statistical, ensemble-based, and kernel-based learning paradigms, allowing for robust comparison and complementary strengths.

Result

Five machine learning models—Logistic Regression, Random Forest, XGBoost, LightGBM, and TabNet—were evaluated on the Titanic dataset to predict passenger survival. The dataset was split into training (80%) and validation (20%) sets, and hyperparameter tuning was performed using Optuna to optimize model performance. Discussion

In this evaluation of machine learning models for the Titanic dataset, five models, namely Logistic Regression, Random Forest, XGBoost, LightGBM, and TabNet, were compared and analyzed from multiple dimensions. This provides comprehensive insights for model performance evaluation and application. The specific discussion is as follows:

Model Performance Comparison

The Random Forest model performed best in multiple metrics, achieving an accuracy of 0.8379, an F1-score of 0.7914. This indicates its excellent ability to distinguish between survived and non-survived passengers. XGBoost had the highest precision (0.8548) but the lowest recall (0.7162), meaning it missed some predictions of survived passengers. Logistic Regression, LightGBM, and TabNet showed similar performance, yet TabNet had the lowest AUC (0.8407), reflecting its weaker discriminative power. These results suggest that different models have their own advantages and disadvantages when dealing with this dataset, and the choice of model should be based on specific application requirements.

Model Behavior Analysis

The classification behavior of Logistic Regression and XGBoost was analyzed in detail through confusion matrices. XGBoost's confusion matrix showed a relatively high number of false negatives, consistent with its low recall rate. However, its high precision indicates that its predictions of survived passengers are relatively accurate. The ROC curve further verified the superiority of the Random Forest model, while other models had lower AUC, indicating weaker discrimination ability. Due to the class imbalance in the dataset (survival rate of approximately 38%), the Precision-Recall curve can better evaluate the performance of the model on the positive class (survived passengers). The Random Forest and XGBoost models maintained higher precision across a wider range of recall values, while other models' curves declined rapidly.

Feature Importance and Model Interpretability

The SHAP values were used to analyze the feature importance of the XGBoost model. It was found that features such as Sex, Pclass, and Age had a significant impact on the model's predictions. Female passengers had a higher likelihood of survival, while a higher Pclass (representing a lower socioeconomic status) reduced the probability of survival, which is consistent with historical facts. This not only reveals the decision-making basis of the model but also provides important information for further optimizing the model or deeply understanding the data.

Consideration of Computational Efficiency

Training time is an important factor in model selection. Logistic Regression had the fastest training speed, while Random Forest had the longest training time due to its ensemble learning nature. This indicates that in practical applications, if there are limitations on computing resources and time, it is necessary to make a trade-off between model performance and computational efficiency.

Research Limitations and Future Directions

This study has certain limitations. Although hyperparameter tuning was carried out, it is possible that the optimal hyperparameter combinations for all models were not explored. In addition, only these five models were used, and there may be other models more suitable for this dataset. Future research can attempt more models and tuning methods, explore ensemble learning strategies, and further optimize model performance. At the same time, more complex feature engineering methods can be considered to extract more valuable features and improve the model's understanding and prediction ability of the data.
